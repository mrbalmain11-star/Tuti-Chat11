# تدقيق صندوق الهدايا ومركز الإدارة على Staging

نقطة الاستعادة هي commit `c19f693fffb32c79505cb31022f129a4652e778d`. اختبار SQL يستعمل جلسات Staging موثقة ويُرجع أي تعديلات تجريبية بـ `ROLLBACK`. نجاح قراءة القسم من الخادم لا يعتبر اختباراً مرئياً أو اختباراً لكل إجراء كتابة.

| القسم | الحالة السابقة أو السبب المثبت | الإصلاح | الاختبار الفعلي |
| --- | --- | --- | --- |
| الإحصائيات | الاستعلام يعرض ثلاثة أعداد فقط | ملخص مفوض يشمل الحضور والحظر والهدايا والعمليات، وروابط للقوائم المدعومة | مطابقة العدد الفعلي ورفض حساب بلا صلاحية |
| المستخدمون | قراءة أحدث السجلات | البطاقة والقائمة الحالية | RPC قراءة السجلات والدليل نجحا |
| تصفير حساب | يتطلب معاينة من المالك | معالج المعاينة والتأكيد الحالي | نجح مسار المعاينة، لم يُنفذ تصفير فعلي |
| الوكالات | قراءة أحدث السجلات | مسار العرض الحالي | نجحت قراءة السجلات وحالة الوكالات |
| الغرف | قراءة أحدث السجلات | مسار العرض الحالي | نجحت قراءة السجلات وحالة الغرفة |
| العمليات وسجل التدقيق | دليل وسجل إداري | مسار القراءة الحالي | نجحت قراءة المستخدمين وسجل التدقيق |
| الآيديات | UUID ظاهر رغم حل الرقم العام مسبقاً | الرقم العام في الواجهة، UUID داخلي | نجحت قراءة الحساب ومنح آيدي في معاملة راجعة |
| إشراف الغرف | حقل الغرفة يتوقع UUID ويعرض UUID للأعضاء | حل الرقم العام في RPC مفوض وإظهار الاسم والرقم | نجحت قراءة الحالة عبر الرقم العام |
| اعتراضات باند الغرف | الإدخال يتوقع UUID | الرقم العام للغرفة في الواجهة | نجحت قراءة الاعتراضات وحل المعرّف |
| طلبات الباند العام | قائمة خدمة العملاء | مسار القائمة الحالي | نجح استعلام القائمة |
| المحظورون | بحث وقائمة وحظر ورفع حظر | المعالجات الحالية | نجح البحث والقائمة، والحظر والرفع داخل معاملة راجعة |
| إجراءات الوكالات | تتطلب صلاحية الإجراء | معالجات القائمة والقرارات الحالية | نجحت قراءة حالة الوكالات |
| طلبات وكالات المضيفين | مسار طلبات قائم | معالجات القائمة والقرارات الحالية | حالة الوكالات نجحت، قرارات الطلبات لم تختبر لكل حالة |
| البلاغات | مسار البلاغات قائم | المعالجات الحالية | نجحت قراءة البلاغات |
| التقارير المالية | تقارير مقيدة بالصلاحيات | مسار التقارير الحالي | نجحت قراءة التقرير بفترة محددة |
| إدارة الشحن وطلبات الوكلاء | شحن المحافظ من الإدارة المالية، وطلبات الوكلاء بقائمة مستقلة | الوصول للمحافظ الثلاث ومسار الطلبات الحالي | نجحت قراءة الطلبات والإصدار وتمويل المحافظ الثلاث داخل معاملة راجعة |
| إدارة الألعاب | قسم منفصل للصيانة والتفعيل | المسار الحالي | نجحت قراءة الإدارة وبلاغات الأخطاء |
| المسؤولون والصلاحيات | منع التفويض خارج الصلاحيات الحالية | مسار الصلاحيات الإداري والمالي الحالي | المسارات حُفظت، لم تختبر مصفوفة كل دور وكل إجراء من الواجهة |
| إدارة البنرات | لوحة حالية | المسار الحالي | مراجعة الربط في المصدر، لم تُجرب كتابة أو رفع ملف |
| الزينة والمتجر | كتالوج مرتبط بقاعدة البيانات | مسار الكتالوج الحالي | نجحت قراءة الكتالوج |
| العروض | لوحة حالية | المسار الحالي | مراجعة الربط في المصدر، لم تُجرّب الكتابة |
| المكافآت اليومية | قسم قراءة | شاشة القراءة الحالية | نجح RPC جدول المكافآت |
| شارات المختبرين | قائمة وعمليات تخص الصلاحيات المعتمدة | المسار الحالي | نجحت قراءة القائمة |
| الخزينة والسجل المركزي | أرصدة وسجل وتفويض مركزي | ثلاثة أرصدة منفصلة في صف | نجحت قراءات الخزينة والسجل والمطابقة |

اختبار `tests/sql/gift-quantities-rollback.sql` يتحقق من الكميات الخمس وإعادة الطلب بالمعرّف نفسه وحصيلة الخصم. الأقسام الفارغة تعكس الكتالوج. الحالات التي تحتاج تحققاً إضافياً تشمل قياس العرض والتمرير على أجهزة Android المختلفة، التشغيل الصوتي والفيديو أثناء التفاعل، وعمليات الإدارة التي لم تُجرّب على جهاز. لم يُطلب إنشاء حزمة Android لهذه الدفعة.
