# Royal Control Studio

Phase 1: manual content administration, no paid AI services. Phase 2: optional AI adapter after launch.

Modules: gifts, store, VIP, levels, CP, events, banners, offers, supported game and room settings.

Workflow: draft -> validated preview -> owner approval -> atomic publication -> versioned rollback. Preserve existing purchased entitlements and financial ledgers. Use existing authoritative server-side owner authorization; never trust client role flags. Public clients read published content only. Keep draft assets private. Audit every publication. Integrate existing domain tables rather than create disconnected duplicate catalogs. Validate compatibility with existing Android clients. No changes to audio or music engines. AI must eventually use the same restricted draft commands, never direct database access.

Implementation status: specification only; schema integration, UI, deployment and end-to-end tests pending.
